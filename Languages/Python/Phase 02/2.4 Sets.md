# 2.4 Sets

## Overview

A set is an unordered collection of unique, hashable items. It answers two questions very well: "is this item in the collection?" and "how do these collections overlap?". Sets remove duplicates automatically and support the same operations as mathematical sets.

## Creation

```python
colors = {"red", "green", "blue"}
numbers = set([1, 2, 2, 3, 3, 3])     # {1, 2, 3}
letters = set("hello")                # {'h', 'e', 'l', 'o'}
empty = set()                         # {} would create an empty dict, not a set
```

Items must be hashable, so a set can hold numbers, strings, and tuples but not lists or dictionaries. Sets have no order and no indexing, so `my_set[0]` is an error, and the printed order may differ from the order you added items.

## Adding and Removing

```python
s = {1, 2, 3}
s.add(4)              # {1, 2, 3, 4}
s.add(2)              # no effect, already present
s.update([5, 6])      # add several items
s.remove(6)           # KeyError if the item is missing
s.discard(99)         # no error if the item is missing
item = s.pop()        # removes and returns an arbitrary item
s.clear()
```

## Membership

```python
allowed = {"GET", "POST"}
print("GET" in allowed)       # True
print("DELETE" not in allowed)  # True
```

## Set Operations

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)     # union: {1, 2, 3, 4, 5, 6}
print(a & b)     # intersection: {3, 4}
print(a - b)     # difference, in a but not in b: {1, 2}
print(a ^ b)     # symmetric difference, in exactly one: {1, 2, 5, 6}

print({1, 2} <= a)          # subset: True
print(a >= {1, 2})          # superset: True
print({1, 2}.isdisjoint({7, 8}))  # True, nothing in common
```

Each operator has a method form that accepts any iterable: `a.union(b)`, `a.intersection(b)`, `a.difference(b)`, `a.symmetric_difference(b)`, `a.issubset(b)`, `a.issuperset(b)`. The in-place versions are `|=`, `&=`, `-=`, and `^=`.

## frozenset

A `frozenset` is an immutable set. Because it is hashable, it can be a dictionary key or a member of another set.

```python
permissions = frozenset({"read", "write"})
cache = {permissions: "editor"}
print(cache[frozenset({"write", "read"})])    # editor
```

## Set Comprehensions

```python
squares = {n * n for n in range(-3, 4)}        # {0, 1, 4, 9}
domains = {email.split("@")[1] for email in ["a@x.com", "b@y.com", "c@x.com"]}
print(domains)                                  # {'x.com', 'y.com'}
```

## Membership-Test Performance

Checking `item in a_list` compares against items one by one. Checking `item in a_set` jumps almost straight to the answer using the item's hash. On large collections this difference is dramatic.

```python
import timeit

numbers_list = list(range(100_000))
numbers_set = set(numbers_list)

print(timeit.timeit(lambda: 99_999 in numbers_list, number=1_000))
print(timeit.timeit(lambda: 99_999 in numbers_set, number=1_000))
```

Run this and compare the two times. The set lookup is typically thousands of times faster at this size. Whenever your code repeatedly asks "is X in this collection?", store the collection as a set.

## Basic Examples

Removing duplicates:

```python
emails = ["a@x.com", "b@y.com", "a@x.com"]
unique_emails = set(emails)
print(len(unique_emails))    # 2
```

Finding what two groups share:

```python
team_a = {"Amina", "Bilal", "Chen"}
team_b = {"Chen", "Dara"}
print(team_a & team_b)    # {'Chen'}
print(team_a - team_b)    # {'Amina', 'Bilal'} in some order
```

## Backend Industry Example

Permission checks, comparing two data sources to decide what to create and delete, and fast filtering against a large blocklist.

```python
# Access control: the user must hold every required permission
REQUIRED_PERMISSIONS = {"orders:read", "orders:write"}
granted = {"orders:read", "orders:write", "users:read"}
print(REQUIRED_PERMISSIONS <= granted)         # True
print(REQUIRED_PERMISSIONS - {"orders:read"})  # what a user would still be missing

# Synchronizing two systems by id
local_ids = {1, 2, 3, 4}
remote_ids = {3, 4, 5, 6}

to_create = remote_ids - local_ids     # exist remotely, missing locally
to_delete = local_ids - remote_ids     # exist locally, gone remotely
to_update = local_ids & remote_ids     # exist in both, compare their data

print(sorted(to_create), sorted(to_delete), sorted(to_update))
# [5, 6] [1, 2] [3, 4]

# Filtering requests against a large, rarely changing blocklist
BLOCKED_IPS = frozenset({"203.0.113.7", "198.51.100.23", "192.0.2.99"})


def is_blocked(ip_address: str) -> bool:
    """Return True if the address is on the blocklist."""
    return ip_address in BLOCKED_IPS


print(is_blocked("203.0.113.7"))       # True
print(is_blocked("10.0.0.1"))          # False


# Removing duplicates while keeping the original order
def unique_in_order(values: list[str]) -> list[str]:
    """Return values without duplicates, in order of first appearance."""
    seen: set[str] = set()
    result: list[str] = []
    for value in values:
        if value not in seen:
            seen.add(value)
            result.append(value)
    return result


print(unique_in_order(["b", "a", "b", "c", "a"]))    # ['b', 'a', 'c']
```

`set(values)` removes duplicates but loses the order, so `unique_in_order` uses a set only for the fast "have I seen this?" check and a list to preserve order. The synchronization pattern replaces nested loops with three set operations.

## Common Mistakes

- Writing `{}` and expecting an empty set. It is an empty dictionary.
- Expecting a set to keep order or support indexing.
- Putting unhashable items such as lists into a set.
- Using `remove` on an item that may be absent instead of `discard`.
- Checking membership repeatedly against a long list.
- Relying on the printed order of a set in tests. Sort it first.

## Summary

Sets hold unique hashable items and are built for fast membership tests and for union, intersection, difference, and subset questions. Use `set()` for an empty set, `frozenset` for an immutable one, and prefer sets whenever code repeatedly asks whether an item is present. Many nested loops over two collections become one set operation.
