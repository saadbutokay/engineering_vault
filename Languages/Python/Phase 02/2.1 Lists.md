# 2.1 Lists

## Overview

A list is an ordered, mutable collection that can hold items of any type. It is the most used data structure in Python: query results, request batches, lines of a file, and queues of work are all lists.

## Creation

```python
empty = []
numbers = [1, 2, 3]
mixed = [1, "two", 3.0, [4, 5]]
letters = list("abc")        # ['a', 'b', 'c']
zeros = [0] * 5              # [0, 0, 0, 0, 0]
counting = list(range(5))    # [0, 1, 2, 3, 4]
```

## Indexing and Slicing

Lists use the same indexing and slicing rules as strings, and unlike strings they can be changed.

```python
colors = ["red", "green", "blue", "yellow"]
print(colors[0])       # red
print(colors[-1])      # yellow
print(colors[1:3])     # ['green', 'blue']
print(colors[::-1])    # reversed copy

colors[0] = "orange"             # replace an item
colors[1:3] = ["lime", "navy"]   # replace a slice
del colors[0]                    # delete an item
```

## Methods

| Method | Effect |
| --- | --- |
| `append(x)` | add one item to the end |
| `extend(iterable)` | add every item of another iterable to the end |
| `insert(i, x)` | insert an item at position `i` |
| `remove(x)` | remove the first item equal to `x`, raises `ValueError` if absent |
| `pop()` / `pop(i)` | remove and return the last item, or the item at `i` |
| `clear()` | remove all items |
| `index(x)` | position of the first item equal to `x` |
| `count(x)` | how many items equal `x` |
| `sort()` | sort in place |
| `reverse()` | reverse in place |
| `copy()` | shallow copy |

```python
items = [3, 1, 2]
items.append(4)            # [3, 1, 2, 4]
items.extend([5, 6])       # [3, 1, 2, 4, 5, 6]
items.insert(0, 99)        # [99, 3, 1, 2, 4, 5, 6]
last = items.pop()         # 6
items.remove(99)           # [3, 1, 2, 4, 5]

print(len(items), min(items), max(items), sum(items))
print(2 in items)          # True
print([1, 2] + [3])        # [1, 2, 3]
print([0] * 3)             # [0, 0, 0]
```

`append` adds a single object, `extend` adds the elements:

```python
a = [1, 2]
a.append([3, 4])    # [1, 2, [3, 4]]
b = [1, 2]
b.extend([3, 4])    # [1, 2, 3, 4]
```

## sort versus sorted

- `list.sort()` sorts the list in place and returns `None`.
- `sorted(iterable)` returns a new sorted list and leaves the original alone. It works on any iterable.

```python
numbers = [3, 1, 2]
print(sorted(numbers))     # [1, 2, 3]
print(numbers)             # [3, 1, 2]
numbers.sort()
print(numbers)             # [1, 2, 3]

numbers = numbers.sort()   # common bug: numbers is now None
```

Both accept `reverse=True` and `key=`. The `key` function is called once per item and the results decide the order.

```python
words = ["banana", "Apple", "cherry"]
print(sorted(words))                    # ['Apple', 'banana', 'cherry']
print(sorted(words, key=str.lower))     # ['Apple', 'banana', 'cherry']
print(sorted(words, key=len))           # ['Apple', 'banana', 'cherry']

users = [{"name": "Amina", "age": 31}, {"name": "Bilal", "age": 25}]
print(sorted(users, key=lambda u: u["age"]))   # Bilal first
```

Sorting is stable: items with equal keys keep their original relative order. To sort by several criteria, return a tuple from the key function. Negating a number sorts that part in descending order.

```python
people = [("Amina", 31), ("Bilal", 25), ("Chen", 31)]
print(sorted(people, key=lambda p: (-p[1], p[0])))
# [('Amina', 31), ('Chen', 31), ('Bilal', 25)]
```

## List Comprehensions

A comprehension builds a new list from an iterable in one expression.

```python
squares = [n * n for n in range(5)]                  # [0, 1, 4, 9, 16]
evens = [n for n in range(10) if n % 2 == 0]         # [0, 2, 4, 6, 8]
clamped = [n if n > 0 else 0 for n in [-2, 3, -1]]   # [0, 3, 0]
lengths = [len(word) for word in ["a", "bb", "ccc"]] # [1, 2, 3]
```

The shape is `[expression for item in iterable if condition]`. A filter `if` goes at the end. A choice between two values (`x if cond else y`) goes at the front.

## Nested Lists

A list of lists represents a table or grid.

```python
grid = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]
print(grid[1][2])                        # 6
flat = [value for row in grid for value in row]   # [1, 2, ..., 9]
```

Build an empty grid with a comprehension. Multiplying a list of lists copies references, not rows:

```python
bad = [[0] * 3] * 3
bad[0][0] = 1
print(bad)       # [[1, 0, 0], [1, 0, 0], [1, 0, 0]]  all rows are one object

good = [[0] * 3 for _ in range(3)]
good[0][0] = 1
print(good)      # [[1, 0, 0], [0, 0, 0], [0, 0, 0]]
```

## Performance Notes

- `append` and `pop()` at the end are fast.
- `insert(0, x)`, `pop(0)`, `remove(x)`, and `x in items` must walk through the list, so they slow down as the list grows. Use a different structure when you do these constantly on large lists.

scores = [72, 95, 88, 64]

## Backend Industry Example

Two routine list tasks in backend work: ordering records with several rules, and splitting a large list into batches for bulk operations such as database inserts or API calls with a size limit.

```python
from decimal import Decimal

orders = [
    {"id": 1, "status": "paid", "total": Decimal("120.00"), "placed": "2026-03-02"},
    {"id": 2, "status": "pending", "total": Decimal("35.50"), "placed": "2026-03-01"},
    {"id": 3, "status": "paid", "total": Decimal("260.00"), "placed": "2026-03-01"},
    {"id": 4, "status": "cancelled", "total": Decimal("15.00"), "placed": "2026-02-28"},
]

STATUS_ORDER = {"pending": 0, "paid": 1, "cancelled": 2}

# Work queue: pending first, then paid, then cancelled. Within a status, oldest
# first so that no order waits forever. ISO dates sort correctly as strings.
work_queue = sorted(
    orders,
    key=lambda order: (STATUS_ORDER[order["status"]], order["placed"]),
)
print([order["id"] for order in work_queue])    # [2, 3, 1, 4]

# The two largest paid orders
paid = [order for order in orders if order["status"] == "paid"]
top_paid = sorted(paid, key=lambda order: order["total"], reverse=True)[:2]
print([order["id"] for order in top_paid])      # [3, 1]


def chunk(items: list, size: int) -> list[list]:
    """Split items into consecutive batches of at most `size` elements."""
    if size <= 0:
        raise ValueError("size must be positive")
    return [items[start:start + size] for start in range(0, len(items), size)]


for batch in chunk(list(range(1, 11)), 4):
    print(batch)    # [1, 2, 3, 4] then [5, 6, 7, 8] then [9, 10]
```

The key function returns a tuple, so one `sorted` call applies two rules. `chunk` uses slicing, which never raises an error at the end of the list, so the last short batch needs no special handling.

## Common Mistakes

- Writing `items = items.sort()` and ending up with `None`.
- Modifying a list while looping over it. Loop over a copy or build a new list instead.
- Using `[[0] * 3] * 3` to create a grid.
- Confusing `append` and `extend`.
- Using `pop(0)` or `insert(0, x)` in a hot loop on a large list.
- Relying on `list.remove` without handling `ValueError` when the item may be missing.
- Writing a comprehension so complex that a normal loop would be clearer.

## Summary

Lists are ordered and mutable. Learn indexing, slicing, and the core methods. Use `sorted` when you need a new list and `sort` for in-place sorting, and use `key=` to control the order, including tuple keys for multiple criteria. Comprehensions build lists concisely. Avoid shared-row grids and avoid operations at the front of large lists.
