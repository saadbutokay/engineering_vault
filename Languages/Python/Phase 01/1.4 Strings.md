# 1.4 Strings

## Overview

A string (`str`) is an immutable sequence of Unicode characters. Strings carry almost all text in a backend system: names, emails, URLs, JSON, log messages, and SQL. This module covers how to create, slice, search, format, and encode them.

## Creating Strings

```python
a = 'single quotes'
b = "double quotes"
c = "It's easy to include an apostrophe this way"
d = """A triple-quoted string
can span several lines."""
```

Single and double quotes are equivalent. Pick one style per project (double quotes are the default of most formatters).

## Indexing and Slicing

Each character has a position starting at `0`. Negative positions count from the end.

```python
text = "python"
print(text[0])      # p
print(text[-1])     # n
print(text[1:4])    # yth   (start included, stop excluded)
print(text[:2])     # py
print(text[2:])     # thon
print(text[::2])    # pto   (every second character)
print(text[::-1])   # nohtyp (reversed)
```

Slice form: `text[start:stop:step]`. An out-of-range index raises `IndexError`, but an out-of-range slice quietly returns what it can.

```python
print("abc"[10:])   # empty string
print("abc"[10])    # IndexError
```

## Immutability

A string cannot be changed after it is created. Every operation that seems to modify it returns a new string.

```python
name = "amina"
name[0] = "A"              # TypeError
name = name.capitalize()   # correct: rebind the name to a new string
```

## Common Methods

```python
s = "  Hello, World  "
print(s.strip())                  # "Hello, World"   remove surrounding whitespace
print(s.lower(), s.upper())
print("hello world".title())      # Hello World
print("a,b,c".split(","))         # ['a', 'b', 'c']
print("-".join(["a", "b", "c"]))  # a-b-c
print("banana".replace("a", "o")) # bonono
print("banana".count("a"))        # 3
print("banana".find("n"))         # 2    returns -1 if not found
print("banana".index("n"))        # 2    raises ValueError if not found
print("report.csv".endswith(".csv"))   # True
print("Hello".startswith("He"))        # True
print("hello world".partition(" "))    # ('hello', ' ', 'world')
print("7".zfill(3))                    # 007
print("v1.2.3".removeprefix("v"))      # 1.2.3
print("line1\nline2".splitlines())     # ['line1', 'line2']
```

Checks: `isdigit()`, `isalpha()`, `isalnum()`, `isspace()`. Membership: `"ell" in "hello"` is `True`.

`join` is the correct way to build a string from many pieces. Repeated `+=` inside a loop is slower and less readable.

## f-strings

An f-string (formatted string literal) embeds expressions directly. It is the preferred formatting tool.

```python
name = "Amina"
age = 30
print(f"{name} is {age} years old")
print(f"Next year: {age + 1}")
```

Format specifications follow a colon:

```python
price = 1234.5
ratio = 0.256
n = 42
print(f"{price:.2f}")      # 1234.50   two decimals
print(f"{price:,.2f}")     # 1,234.50  thousands separator
print(f"{ratio:.1%}")      # 25.6%
print(f"{n:05d}")          # 00042     zero padded
print(f"{'left':<10}|")    # left      |
print(f"{'right':>10}|")   #      right|
print(f"{'mid':^10}|")     #    mid    |
print(f"{name!r}")         # 'Amina'   repr form, shows quotes
print(f"{age=}")           # age=30    prints the expression and its value
```

## The format() Method and Older Styles

```python
print("{} is {}".format("Amina", 30))
print("{0} {1} {0}".format("a", "b"))
print("{name}".format(name="Amina"))
print(format(3.14159, ".2f"))          # 3.14
```

Older code uses `%` formatting: `"%s is %d" % ("Amina", 30)`. You will meet it in existing code, but write f-strings in new code. Use `format()` or `str.format` when the template string is stored separately from the values.

## Escape Sequences and Raw Strings

| Sequence | Meaning |
| --- | --- |
| `\n` | newline |
| `\t` | tab |
| `\\` | backslash |
| `\'` and `\"` | quote characters |
| `\u00e9` | Unicode character by code point |

A raw string, written with an `r` prefix, treats backslashes literally. It is the right choice for Windows paths and regular expressions.

```python
print("C:\new\table")     # \n and \t are interpreted as escapes
print(r"C:\new\table")    # C:\new\table
```

A raw string cannot end with an odd number of backslashes.

## Multiline Strings

```python
query = """
SELECT id, email
FROM users
WHERE active = TRUE
"""
```

Adjacent string literals inside parentheses are joined automatically, which keeps long messages within the line length limit:

```python
message = (
    "The order could not be processed because "
    "the payment method was declined."
)
```

## Unicode

Python 3 strings are sequences of Unicode code points, so they hold text from any language.

```python
print(len("hello"))    # 5
print("naive".upper(), "caf\u00e9")
print(ord("A"))        # 65   code point of a character
print(chr(97))         # a    character for a code point
```

One visible character can sometimes be built from several code points (for example, a letter plus a combining accent). Text from different sources may need normalization with `unicodedata.normalize("NFC", text)` before comparing.

## bytes versus str

- `str` is text: characters.
- `bytes` is raw data: numbers from 0 to 255. Files, network sockets, and HTTP bodies deliver bytes.

Converting between them requires an encoding. UTF-8 is the standard.

```python
text = "caf\u00e9"
data = text.encode("utf-8")
print(data)                    # b'caf\xc3\xa9'
print(len(text), len(data))    # 4 5
print(data.decode("utf-8"))    # cafe with the accent restored
print(b"abc"[0])               # 97: indexing bytes gives integers
```

Always state the encoding explicitly. Decoding bytes with the wrong encoding raises `UnicodeDecodeError` or produces garbled text. `errors="replace"` substitutes damaged characters instead of failing:

```python
print(b"caf\xe9".decode("utf-8", errors="replace"))
```

## Basic Examples

```python
first = "amina"
last = "rahman"
full = f"{first.title()} {last.title()}"
print(full)                      # Amina Rahman

sentence = "the quick brown fox"
words = sentence.split()
print(len(words))                # 4
print(" ".join(reversed(words))) # fox brown quick the

def receipt_line(name, quantity, total):
    return f"{name:<15} x{quantity:<3} {total:>9,.2f}"

print(receipt_line("Notebook", 2, 1499.5))
```

## Backend Industry Example

Two routine tasks: cleaning user input and decoding a request body received as bytes.

```python
def normalize_email(raw: str) -> str:
    """Return a cleaned, lower-case email address or raise ValueError."""
    cleaned = raw.strip().lower()
    if cleaned.count("@") != 1:
        raise ValueError(f"Invalid email address: {raw!r}")
    local, domain = cleaned.split("@")
    if not local or "." not in domain:
        raise ValueError(f"Invalid email address: {raw!r}")
    return f"{local}@{domain}"


def decode_body(body: bytes) -> str:
    """Decode an HTTP request body as UTF-8 text."""
    try:
        return body.decode("utf-8")
    except UnicodeDecodeError as exc:
        raise ValueError("Request body is not valid UTF-8") from exc


print(normalize_email("  Amina.Rahman@Example.COM "))   # amina.rahman@example.com
```

Notice `!r` in the error message. It shows the raw value with quotes, so invisible characters such as trailing spaces are visible in logs. Normalizing before storing prevents two accounts being created for `A@x.com` and `a@x.com`.

## Common Mistakes

- Trying to modify a string in place.
- Building strings with `+` in a loop instead of `join`.
- Building SQL or shell commands with f-strings from user input. This creates injection vulnerabilities; use parameterized queries.
- Forgetting to specify the encoding when reading, writing, encoding, or decoding.
- Using normal strings for Windows paths and getting unexpected `\n` or `\t`.
- Comparing text without normalizing case or whitespace.

## Summary

Strings are immutable Unicode sequences. Master indexing and slicing, the common methods, and f-strings with format specifications. Use raw strings for backslash-heavy text and triple quotes for multiline text. Keep `str` and `bytes` separate and always convert with an explicit encoding, normally UTF-8.
