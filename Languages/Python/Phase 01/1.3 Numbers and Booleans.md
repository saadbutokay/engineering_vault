# 1.3 Numbers and Booleans

## Overview

Python has several numeric types, each with different strengths. Choosing the right one matters most in two areas: floating-point rounding errors and money. This module covers the numeric types, the operators, truthiness, and the `math` module.

## Numeric Types

### int

Whole numbers of any size. Python integers do not overflow.

```python
big = 2 ** 100
print(big)              # 1267650600228229401496703205376
population = 8_000_000_000     # underscores improve readability
mask = 0xFF                    # hexadecimal, value 255
flags = 0b1010                 # binary, value 10
```

### float

Numbers with a decimal point, stored as 64-bit binary floating-point values (IEEE 754). Many decimal fractions cannot be stored exactly.

```python
print(0.1 + 0.2)               # 0.30000000000000004
print(0.1 + 0.2 == 0.3)        # False
print(round(2.675, 2))         # 2.67, not 2.68
```

Never compare floats with `==`. Use a tolerance:

```python
import math

print(math.isclose(0.1 + 0.2, 0.3))   # True
```

### bool

`True` and `False`. `bool` is a subclass of `int`, so `True == 1` and `False == 0`, and booleans can be used in arithmetic.

```python
print(True + True)             # 2
print(sum([True, False, True]))  # 2, counts the True values
```

### complex

Numbers with a real and an imaginary part, written with `j`. Rare in backend work, common in science and engineering.

```python
z = 3 + 4j
print(z.real, z.imag)          # 3.0 4.0
print(abs(z))                  # 5.0
```

### Decimal

Exact decimal arithmetic, as people expect from money and accounting. Always create a `Decimal` from a string, not from a float.

```python
from decimal import Decimal

print(Decimal("0.1") + Decimal("0.2"))                      # 0.3
print(Decimal("0.1") + Decimal("0.2") == Decimal("0.3"))    # True
print(Decimal(0.1))   # long inexact value: the float was already wrong
```

### Fraction

Exact rational numbers.

```python
from fractions import Fraction

print(Fraction(1, 3) + Fraction(1, 6))   # 1/2
```

## Arithmetic Operators

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| `+` `-` `*` | add, subtract, multiply | `7 * 3` | `21` |
| `/` | true division, always a float | `7 / 2`, `4 / 2` | `3.5`, `2.0` |
| `//` | floor division | `7 // 2`, `-7 // 2` | `3`, `-4` |
| `%` | remainder | `7 % 3`, `-7 % 3` | `1`, `2` |
| `**` | power | `2 ** 10` | `1024` |

Notes:

- `//` rounds toward negative infinity, so `-7 // 2` is `-4`.
- The result of `%` takes the sign of the right operand, so `-7 % 3` is `2`.
- `divmod(17, 5)` returns both quotient and remainder: `(3, 2)`.
- `round()` uses banker's rounding for exact halves: `round(2.5)` is `2` and `round(3.5)` is `4`.
- Augmented forms exist: `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=`.

## Comparison Operators

`==`, `!=`, `<`, `>`, `<=`, `>=`. Python allows chaining:

```python
age = 25
print(18 <= age < 65)    # True, same as 18 <= age and age < 65
```

## Logical Operators

`and`, `or`, `not`. They short-circuit: evaluation stops as soon as the result is known. They return one of their operands, not necessarily `True` or `False`.

```python
print(0 or 5)              # 5
print("" or "default")     # default
print(3 and 4)             # 4
print(None and 4)          # None
print(not 0)               # True
```

Precedence from highest to lowest: `not`, then `and`, then `or`. Use parentheses when mixing them.

## Bitwise Operators

They work on the binary digits of integers.

| Operator | Meaning | Example | Result |
| --- | --- | --- | --- |
| `&` | AND | `5 & 3` | `1` |
| `\|` | OR | `5 \| 3` | `7` |
| `^` | XOR | `5 ^ 3` | `6` |
| `~` | NOT | `~5` | `-6` |
| `<<` | shift left | `1 << 3` | `8` |
| `>>` | shift right | `16 >> 2` | `4` |

## Truthiness and Falsiness

Any object can be used in a condition. These values are falsy:

- `None` and `False`
- zero of any numeric type: `0`, `0.0`, `0j`, `Decimal("0")`
- empty containers and strings: `""`, `[]`, `()`, `{}`, `set()`, `range(0)`

Everything else is truthy. `bool(value)` shows the result.

```python
items = []
if not items:
    print("no items")

print(bool("False"))    # True: a non-empty string is always truthy
```

## The math Module

```python
import math

print(math.sqrt(16))      # 4.0
print(math.floor(3.7))    # 3
print(math.ceil(3.2))     # 4
print(math.pi)            # 3.141592653589793
print(math.gcd(12, 18))   # 6
print(math.log(100, 10))  # 2.0
print(math.inf)           # inf
print(math.isnan(float("nan")))  # True
```

## Backend Industry Example

Money must never be stored in floats. This function calculates an invoice total with `Decimal` and an explicit rounding rule.

```python
from decimal import ROUND_HALF_UP, Decimal

TWO_PLACES = Decimal("0.01")


def calculate_invoice_total(
    unit_price: Decimal, quantity: int, tax_rate: Decimal
) -> Decimal:
    """Return the invoice total including tax, rounded to cents."""
    if quantity <= 0:
        raise ValueError("quantity must be positive")
    subtotal = unit_price * quantity
    tax = subtotal * tax_rate
    return (subtotal + tax).quantize(TWO_PLACES, rounding=ROUND_HALF_UP)


total = calculate_invoice_total(Decimal("19.99"), 3, Decimal("0.075"))
print(total)    # 64.47  (subtotal 59.97 plus tax 4.49775 is 64.46775)
```

Permission flags stored as bits in a single integer are common in access control and feature flags.

```python
READ = 0b001
WRITE = 0b010
DELETE = 0b100

permissions = READ | WRITE              # grant two permissions

can_write = bool(permissions & WRITE)   # True
can_delete = bool(permissions & DELETE) # False
permissions |= DELETE                   # grant one more
permissions &= ~WRITE                   # revoke one
```

## Common Mistakes

- Using `float` for money and then finding totals that are off by a cent.
- Creating `Decimal(0.1)` from a float instead of `Decimal("0.1")`.
- Comparing floats with `==`.
- Forgetting that `/` always returns a float, even for `4 / 2`.
- Writing `if value:` when `0` is a legitimate value.
- Mixing up `and` and `&`: `and` is logical and `&` is bitwise.

## Summary

Use `int` for whole numbers, `float` for measurements where tiny errors are acceptable, and `Decimal` for money. Compare floats with `math.isclose`. Understand floor division, remainder, and banker's rounding. Logical operators short-circuit and return operands. Know the list of falsy values and use bitwise operators for flags.
