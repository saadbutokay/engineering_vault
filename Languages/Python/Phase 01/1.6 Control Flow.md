# 1.6 Control Flow

## Overview

Control flow decides which statements run and how many times. It consists of decisions (`if`, `match`) and repetition (`while`, `for`), plus the keywords that change a loop's behaviour.

## if, elif, else

```python
score = 72

if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"

print(grade)   # B
```

Conditions are checked from top to bottom and only the first matching branch runs. Any expression can be a condition, so truthiness rules apply: an empty list, `0`, `""`, and `None` are false.

```python
items = []
if items:
    print("has items")
else:
    print("empty")
```

## Conditional Expressions

A one-line form that produces a value:

```python
status = "adult" if age >= 18 else "minor"
```

Use it for simple choices. Switch to a full `if` statement when it becomes hard to read.

## match and case

`match` (Python 3.10 and newer) compares a value against patterns. It is more than a switch statement because it can take apart sequences and dictionaries.

Literal and alternative patterns, with `_` as the catch-all:

```python
status_code = 404

match status_code:
    case 200 | 201:
        print("success")
    case 404:
        print("not found")
    case _:
        print("other")
```

Sequence patterns bind parts of the value to names:

```python
command = "go north"

match command.split():
    case ["go", direction]:
        print(f"Going {direction}")
    case ["quit"]:
        print("Bye")
    case _:
        print("Unknown command")
```

A guard adds an extra condition with `if`:

```python
match point:
    case (x, y) if x == y:
        print("on the diagonal")
    case (x, y):
        print(f"at {x}, {y}")
```

Mapping patterns match dictionaries that contain at least the listed keys, which is useful for JSON data.

## while Loops

`while` repeats as long as its condition is true.

```python
count = 3
while count > 0:
    print(count)
    count -= 1
print("liftoff")
```

Make sure something inside the loop eventually makes the condition false, otherwise the loop never ends. An intentional endless loop is written `while True` and exited with `break`.

## for Loops

`for` visits each item of an iterable such as a list, string, dictionary, or range.

```python
for name in ["Amina", "Bilal", "Chen"]:
    print(name)

for letter in "abc":
    print(letter)
```

`range` generates numbers lazily:

```python
range(5)          # 0, 1, 2, 3, 4
range(2, 6)       # 2, 3, 4, 5
range(10, 0, -3)  # 10, 7, 4, 1
```

Two helpers used constantly with `for`:

```python
names = ["Amina", "Bilal", "Chen"]
scores = [90, 75, 82]

for position, name in enumerate(names, start=1):
    print(position, name)

for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

## break, continue, and Loop else

- `break` exits the loop immediately.
- `continue` skips to the next iteration.
- `else` on a loop runs only if the loop ended normally, without `break`.

```python
numbers = [4, 8, 15, 16]

for n in numbers:
    if n < 0:
        print("negative number found")
        break
else:
    print("all numbers are non-negative")
```

## The Walrus Operator

`:=` assigns a value as part of an expression, which avoids computing something twice.

```python
data = [1, 2, 3, 4]

if (n := len(data)) > 3:
    print(f"list is long ({n} items)")

while (line := input("> ")) != "quit":
    print(f"you typed {line}")
```

Use it sparingly. If it makes a line harder to read, use two statements.

## Basic Examples

Sum of the even numbers up to 10:

```python
total = 0
for number in range(1, 11):
    if number % 2 == 0:
        total += number
print(total)    # 30
```

Prime check using loop `else`:

```python
n = 29
for divisor in range(2, int(n ** 0.5) + 1):
    if n % divisor == 0:
        print(f"{n} is not prime")
        break
else:
    print(f"{n} is prime")
```

Skipping blank lines:

```python
lines = ["first", "", "second", ""]
for line in lines:
    if not line:
        continue
    print(line)
```

## Backend Industry Example

A retry loop with exponential backoff, the standard way to call an unreliable network service, and an event dispatcher built on `match` and mapping patterns.

```python
import time
from collections.abc import Callable

MAX_ATTEMPTS = 4
BASE_DELAY_SECONDS = 0.5


def fetch_with_retry(fetch: Callable[[], tuple[int, dict]]) -> dict:
    """Call fetch until it succeeds, retrying temporary failures."""
    for attempt in range(1, MAX_ATTEMPTS + 1):
        status_code, payload = fetch()
        match status_code:
            case 200 | 201:
                return payload
            case 429 | 502 | 503 | 504:
                if attempt < MAX_ATTEMPTS:
                    time.sleep(BASE_DELAY_SECONDS * 2 ** (attempt - 1))
            case 404:
                raise LookupError("resource not found")
            case _:
                raise RuntimeError(f"unexpected status {status_code}")
    raise RuntimeError(f"gave up after {MAX_ATTEMPTS} attempts")
```

The delays are 0.5, 1, and 2 seconds. Temporary failures (429, 502, 503, 504) are retried, permanent ones fail immediately, and the function never sleeps after the final attempt.

```python
def handle_event(event: dict) -> str:
    """Route a webhook event to the right action."""
    match event:
        case {"type": "order.created", "order_id": order_id}:
            return f"create:{order_id}"
        case {"type": "order.cancelled", "order_id": order_id, "reason": reason}:
            return f"cancel:{order_id}:{reason}"
        case {"type": event_type}:
            return f"ignored:{event_type}"
        case _:
            raise ValueError("event has no type")
```

Each `case` checks that the dictionary has the listed keys and binds their values to names in one step. Order matters: more specific patterns come first and the general pattern comes last.

## Common Mistakes

- Writing an endless `while` loop by forgetting to update the condition.
- Using `=` instead of `==` in a condition. Python reports a syntax error, which protects you.
- Off-by-one errors with `range`, where the stop value is excluded.
- Modifying a list while looping over it.
- Using `match` for a handful of simple cases where `if` and `elif` are clearer.
- Forgetting that `case _` is needed to handle unexpected input.
- Overusing the walrus operator until lines become hard to read.

## Summary

Use `if`, `elif`, and `else` for decisions, and `match` when you need to dispatch on the shape or value of data. Use `for` to iterate over a collection and `while` when the number of repetitions is not known in advance. `break` exits, `continue` skips, and loop `else` detects that no `break` occurred. In production code, loops that call external systems need a maximum number of attempts, a delay between them, and a clear failure at the end.
