# 5.5 pathlib, os, and the Filesystem

## Overview

Working with files means working with paths, directories, permissions, and the environment. The `pathlib` module represents paths as objects and is the modern way to handle them. The `os` module exposes operating system features, `shutil` handles higher-level file operations such as copying trees, and `tempfile` creates temporary files safely.

## pathlib.Path

A `Path` represents a location on disk. Creating one does not touch the disk, and the file does not need to exist.

```python
from pathlib import Path

folder = Path("reports")
file_path = folder / "2026" / "march.csv"     # the / operator joins paths
print(file_path)
# reports/2026/march.csv (backslashes on Windows)

print(Path.cwd())                             # current working directory
print(Path.home())                            # the user's home directory
```

The `/` operator handles the correct separator for the operating system, so there is no need to build paths with string concatenation.

### Parts of a Path

```python
p = Path("/data/exports/orders.2026.csv")

print(p.name)        # orders.2026.csv
print(p.stem)        # orders.2026
print(p.suffix)      # .csv
print(p.suffixes)    # ['.2026', '.csv']
print(p.parent)      # /data/exports
print(p.parts)       # ('/', 'data', 'exports', 'orders.2026.csv')
print(p.with_suffix(".json"))        # /data/exports/orders.2026.json
print(p.with_name("summary.csv"))    # /data/exports/summary.csv
print(p.relative_to("/data"))        # exports/orders.2026.csv
print(p.is_absolute())               # True
```

### Resolving Paths

```python
Path("data/../data/file.txt").resolve()
# absolute path, with .. and symlinks resolved
Path("file.txt").absolute()                # absolute path without resolving symlinks
```

### Checking and Creating

```python
p = Path("output")

p.exists()
p.is_file()
p.is_dir()

p.mkdir(parents=True, exist_ok=True)       # create the folder and any missing parents
(p / "a.txt").touch()                      # create an empty file or update its time
```

`exist_ok=True` makes `mkdir` safe to call when the folder is already there.

### Reading and Writing

```python
path = Path("output/note.txt")

path.write_text("hello\n", encoding="utf-8")
text = path.read_text(encoding="utf-8")

path.write_bytes(b"\x00\x01")
data = path.read_bytes()

with path.open("a", encoding="utf-8") as f:     # same as open(path, ...)
    f.write("more\n")
```

`read_text` and `write_text` are convenient for small files. Use `open()` with iteration for large ones.

### Removing and Renaming

```python
path.rename("output/renamed.txt")
path.replace("output/other.txt")        # replaces the target if it exists
path.unlink(missing_ok=True)            # delete a file, no error if it is absent
Path("output").rmdir()                  # remove an empty folder only
```

## Traversing Directories

```python
root = Path("project")

for item in root.iterdir():                 # direct children only
    print(item.name, item.is_dir())

list(root.glob("*.py"))                     # .py files directly inside root
list(root.rglob("*.py"))                    # .py files in root and all subfolders
list(root.glob("**/*.md"))                  # same idea as rglob

for path in sorted(root.rglob("*")):
    if path.is_file():
        print(path.relative_to(root), path.stat().st_size)
```

`os.walk` visits a tree top-down and yields the folder, its subfolders, and its files:

```python
import os

for folder, subfolders, files in os.walk("project"):
    for name in files:
        print(os.path.join(folder, name))
```

Python 3.12 added `Path.walk()`, which works the same way and yields `Path` objects.

## The os Module

### Environment variables

`os.environ` is a dictionary-like mapping of the process's environment variables. Keys and values are always strings.

```python
import os

home = os.environ.get("HOME")                       # None if missing
port = int(os.environ.get("PORT", "8000"))          # default, then convert
debug = os.environ.get("DEBUG", "false").lower() == "true"

os.environ["APP_MODE"] = "test"
# visible to this process and its children
secret = os.environ["SECRET_KEY"]                   # KeyError if missing: fail early
```

`os.getenv("PORT", "8000")` is a shorthand for `os.environ.get`.

### Other useful functions

```python
os.getcwd()          # current directory (Path.cwd() is the modern form)
os.listdir(".")      # names in a folder
os.cpu_count()       # number of CPUs
os.getpid()          # the current process id
os.name              # 'posix' or 'nt'
os.sep               # path separator for this platform
```

## shutil

`shutil` handles operations that work on whole files and trees.

```python
import shutil

shutil.copy("a.txt", "b.txt")                  # copy a file
shutil.copy2("a.txt", "b.txt")                 # copy and keep timestamps
shutil.copytree("src_dir", "dst_dir", dirs_exist_ok=True)   # copy a whole folder
shutil.move("old.txt", "archive/old.txt")
shutil.rmtree("build")                         # delete a folder and everything in it
shutil.make_archive("backup", "zip", "data")   # create backup.zip from the data folder
print(shutil.disk_usage("/"))                  # total, used, free bytes
print(shutil.which("python"))                  # location of an executable, or None
```

`rmtree` deletes without asking and without a recycle bin. Check the path before calling it.

## tempfile

`tempfile` creates temporary files and folders with unique names, in the right location for the operating system, with safe permissions.

```python
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as folder:
    work_file = Path(folder) / "scratch.txt"
    work_file.write_text("temporary", encoding="utf-8")
# the folder and its content are deleted here

with tempfile.NamedTemporaryFile(
    "w", suffix=".csv", delete=False, encoding="utf-8"
) as tmp:
    tmp.write("a,b\n")
print(tmp.name)                 # the file still exists because delete=False

print(tempfile.gettempdir())    # the system temporary directory
```

Use `tempfile` instead of inventing names like `/tmp/data.txt`. Fixed names collide between processes and are guessable by other users on the machine.

## Basic Examples

```python
from pathlib import Path

base = Path("demo")
(base / "logs").mkdir(parents=True, exist_ok=True)
(base / "logs" / "a.log").write_text("first\n", encoding="utf-8")
(base / "logs" / "b.log").write_text("second\n", encoding="utf-8")

for log in sorted(base.glob("logs/*.log")):
    print(log.name, log.stat().st_size)

total_size = sum(p.stat().st_size for p in base.rglob("*") if p.is_file())
print(total_size)
```

## Backend Industry Example

Three filesystem tasks every backend service meets: accepting a user-supplied file name safely, deleting old files according to a retention rule, and locating a data directory from configuration.

```python
import os
import tempfile
import time
from pathlib import Path


def safe_join(base_dir: Path, user_supplied: str) -> Path:
    """Join a user-supplied relative path to base_dir without escaping it.

    Rejects inputs such as '../../etc/passwd' (path traversal) and absolute paths.
    """
    base = base_dir.resolve()
    candidate = (base / user_supplied).resolve()
    if not candidate.is_relative_to(base):
        raise ValueError(f"path escapes the upload directory: {user_supplied!r}")
    return candidate


def delete_older_than(directory: Path, days: int, pattern: str = "*") -> list[Path]:
    """Delete files matching pattern that were last modified more than `days` ago."""
    cutoff = time.time() - days * 86_400
    deleted = []
    for path in directory.rglob(pattern):
        if path.is_file() and path.stat().st_mtime < cutoff:
            path.unlink()
            deleted.append(path)
    return deleted


def data_directory() -> Path:
    """Return the application data directory, creating it if needed."""
    configured = os.environ.get("APP_DATA_DIR")
    base = Path(configured) if configured else Path.home() / ".orders-service"
    base.mkdir(parents=True, exist_ok=True)
    return base


with tempfile.TemporaryDirectory() as workdir:
    uploads = Path(workdir) / "uploads"
    uploads.mkdir()

    print(safe_join(uploads, "invoices/march.pdf").name)       # march.pdf
    for attack in ("../secret.txt", "/etc/passwd", "a/../../b"):
        try:
            safe_join(uploads, attack)
        except ValueError as exc:
            print("rejected:", exc)

    old = uploads / "old.tmp"
    new = uploads / "new.tmp"
    old.write_text("x", encoding="utf-8")
    new.write_text("y", encoding="utf-8")
    forty_days_ago = time.time() - 40 * 86_400
    os.utime(old, (forty_days_ago, forty_days_ago))            # pretend it is old

    print([p.name for p in delete_older_than(uploads, days=30, pattern="*.tmp")])
    # ['old.tmp']

    os.environ["APP_DATA_DIR"] = str(Path(workdir) / "appdata")
    print(data_directory().name)                               # appdata
```

`safe_join` resolves the final path and then verifies that it still lies inside the allowed folder. Resolving first matters, because `..` segments and symbolic links are only visible after resolution. Validating the text of the name by searching for `..` is not reliable. The retention function only touches files, never folders, and returns what it deleted so the caller can log it. Reading the data location from an environment variable lets the same code run on a laptop, in a container, and on a server.

## Common Mistakes

- Building paths with string concatenation or hard-coded separators.
- Accepting a user-supplied file name and joining it to a folder without checking where it ends up (path traversal).
- Assuming relative paths are relative to the script instead of the current working directory.
- Calling `shutil.rmtree` or `unlink` on a path that was computed incorrectly.
- Using fixed names in the shared temporary directory instead of `tempfile`.
- Treating environment variables as typed values. They are always strings, so `"false"` is truthy until converted.
- Using `Path.read_text()` on a very large file.

## Summary

Use `pathlib.Path` to build, inspect, and traverse paths, with the `/` operator for joining, `mkdir(parents=True, exist_ok=True)` for creating folders, and `glob` and `rglob` for searching. Use `os.environ` for configuration, `shutil` for copying and removing trees, and `tempfile` for temporary data. Always validate user-supplied paths by resolving them and checking that they remain inside the intended directory.
